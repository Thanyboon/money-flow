# MONEY FLOW — รุ่นไม่ต้องใส่รหัสผ่าน (v1.1.0)

รุ่นนี้ปรับให้เปิดหน้าเว็บแล้วโหลด Dashboard โดยไม่ต้อง Login หรือกรอกรหัสผ่าน

## ไฟล์ในแพ็กเกจ
- `index.html`
- `Code.gs`
- `manifest.json`
- `service-worker.js`
- `icon.svg`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`

## ข้อควรระวังสำคัญ
เจ้าของแอปยืนยันให้ใช้โหมดไม่ต้องใส่รหัสผ่านและยอมรับความเสี่ยงแล้ว
**ทุกคนที่ทราบ URL ของ Apps Script Web App สามารถอ่านข้อมูลและเพิ่ม/แก้ไข/ลบข้อมูลใน Google Sheets ผ่าน API ได้**
การซ่อน URL ในหน้าเว็บไม่ใช่ระบบรักษาความปลอดภัย และไม่ควรนำ URL ไปเผยแพร่ในที่สาธารณะ
ควรใช้กับข้อมูลทดลองเท่านั้น หรือข้อมูลที่ยอมรับให้ผู้เข้าถึง URL อ่าน/แก้ไขได้

## ขั้นตอนอัปเดต Apps Script
1. เปิดโปรเจกต์ Google Apps Script เดิม
2. เปิด `Code.gs` แล้วแทนที่โค้ดทั้งหมดด้วยไฟล์ `Code.gs` ในแพ็กเกจนี้
3. กด Save
4. เลือก Deploy > Manage deployments
5. กดไอคอนดินสอของ Web App เดิม
6. เลือก New version แล้วกด Deploy
7. คง URL `/exec` เดิมไว้
8. เปิด URL เดิมตามด้วย `?action=ping` ต้องเห็น `ok:true` และ version `1.1.0-public-no-password`

## ขั้นตอนอัปเดต GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในแพ็กเกจไปยัง root ของ repository เดิม และแทนที่ไฟล์เดิม
2. ตรวจให้แน่ใจว่า `index.html`, `manifest.json`, `service-worker.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` อยู่ระดับ root
3. รอ GitHub Pages เผยแพร่
4. ปิดแอปจาก App Switcher บน iPad แล้วเปิดใหม่
5. ถ้ายังเป็นหน้าเก่า ให้ปิด/เปิด Safari หรือ reload หน้าเว็บ

## สิ่งที่เปลี่ยน
- ตัดหน้าล็อกอินและช่องรหัสผ่านออก
- ตัดการสร้างและตรวจ Session Token
- `bootstrap` และ `mutate` ใช้งานได้โดยไม่ต้องมี token
- ครั้งแรกจะถาม Apps Script Web App URL; ครั้งต่อไปจำ URL ไว้ในอุปกรณ์
- คงชื่อชีตและข้อมูลเดิม ไม่สั่ง initializeDatabase ซ้ำ และไม่ลบข้อมูล
- คง Light/Dark Mode, ธุรกรรม, กระเป๋าเงิน, เป้าหมายออม, งบประมาณ, หารบิล, ตรวจสอบบัญชี และรายงาน

## ข้อจำกัด
- การบันทึกข้อมูลยังต้องเชื่อมต่ออินเทอร์เน็ต
- Offline cache แสดงข้อมูลล่าสุดที่เคยซิงค์เท่านั้น ไม่ได้เข้าคิวบันทึก
- หารบิลยังแบ่งเท่ากันทุกคน
